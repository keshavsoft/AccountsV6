AccountsV6

AccountsV6 is a modular accounting and table-management ecosystem built using Node.js, Express v5, reusable KSTable workflows, JSON-based storage, configurable columns, and KeshavSoft npm generators.

Core Features

KSTable Integration

Dynamically render searchable, filterable, and configurable tables using reusable KSTable workflows.

Columns Driven UI

Configure columns, totals, balances, searches, widths, and layouts using JSON configuration.

Version Based Frontend

Supports frontend versions like v5, v7, v8, and v9 for scalable frontend evolution.

File Based Storage

Uses JSON-based storage instead of requiring external database setup during development.

Supported Endpoints

ShowAll

Fetch all records dynamically from JSON-based tables.

Insert

Insert new records into configurable table structures.

Delete

Delete records dynamically using reusable endpoint workflows.

Alter

Modify and update existing records dynamically.

Find

Fetch single records using configurable query parameters.

FilterColumns

Dynamically filter table data using column-based searches.

Distinct

Fetch unique column values for searchable datalists.

Filter

Apply reusable filtering workflows across configurable tables.

Generate APIs

Generate reusable API endpoint structures dynamically using KeshavSoft npm modules.

npx @keshavsoft/kschema-api-gen CreateApi Api/V2/sellers/ShowAll
  • ✔ Generates endpoint folders automatically
  • ✔ Creates controller and service files
  • ✔ Supports version-based APIs
  • ✔ Reduces repetitive backend setup work
